Access grants

Who may use which models, offerings, and credentials. A deny beats an allow; a user role without any grant is denied, an admin is allowed by default. An API key with no grants of its own inherits its owner's access and never exceeds the account. The first grant on a user's key replaces that inheritance with an explicit scope: the key keeps only what its own grants allow, so a key with only deny rows is denied everything. An admin's key is already allowed, so only deny rows narrow it.
